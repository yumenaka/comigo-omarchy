# comigo-omarchy

[English](README.md) | [中文](README_ZH.md) | [日本語](README_JP.md)

漫画・画像リーダー [Comigo](https://github.com/yumenaka/comigo) を操作する Omarchy ステータスバーのパネルです。読書用リンクと QR コードを開き、サーバーの状態を確認し、ローカルの Comigo CLI を管理できます。UI は日本語・英語・中国語に対応しています。

## インストール

```bash
omarchy plugin add https://github.com/yumenaka/comigo-omarchy --enable
```

プラグイン ID は `yumenaka.comigo` です。ステータスバーのアイコンをクリックして開きます。ローカル CLI が見つからない場合はサービスページが開き、インストールボタンから comigo.xyz の対応プラットフォーム向け `comi` リリースを取得できます。PATH に `/usr/bin` があれば `/usr/bin/comi`、なければ `~/.local/bin/comi` にインストールします。システムディレクトリへの書き込みには管理者認証が必要です。既存ファイルは上書きしません。

## 削除

```bash
omarchy plugin remove yumenaka.comigo
```

ローカルソースからインストールした場合は、そのソースディレクトリで `bash install.sh --uninstall` を実行します。削除しても設定と書庫は保持され、Comigo は停止しません。サービスを継続させたくない場合は、先にプラグインで停止してください。

## 依存関係

Shell プラグイン対応の Omarchy、Bash、curl が必要です。UI とファイル操作には Quickshell とホストの基本ツールを使用します。サーバーには **Comigo v1.3.5 以降**が必要です。ローカルモードには Comigo CLI も必要ですが、リモートモードではローカル CLI は不要です。

## ページ

| ページ | 機能 |
| --- | --- |
| 概要 | 読書 URL の表示・コピー、QR コード、ローカル IP の切り替え |
| 状態 | サービス状態、バージョン、書籍数と接続数、転送速度と累計通信量 |
| サービス | ローカルサービスの起動・停止・再起動、自動起動、ログ、CLI のインストール、更新確認 |
| 設定 | ローカル・リモート接続、書庫と CLI のパス、ログイン、外部アクセス、ファイアウォール、使用中の設定ファイル情報 |

## 言語

UI は既定でシステム言語に従い、未対応の言語では英語を使います。サイドバーの EN / 中文 / 日本語 ボタンで切り替えられます。選択は `settings.json` に保存され、Shell の再起動後も保持されます。

## ローカル書庫に接続する

1. サイドバーで「ローカル」を選び、「設定」を開きます。
2. サービスのループバック URL を入力します。通常は `http://127.0.0.1:1234/` です。プロトコル、ポート、BasePath を一致させてください。例：`http://127.0.0.1:1234/books/`。
3. CLI パスを空欄にすると PATH 上の `comi` または `comigo` を検索します。フルパスの指定も可能です。書庫ディレクトリを空欄にすると Comigo の既定の規則を使います。指定する場合は存在するディレクトリを選んでください。
4. 保存し、「サービス」で Comigo を起動します。認証が必要な場合は「設定」でログインします。

接続 URL はパネルの接続先であり、サーバーのポート、TLS、BasePath は変更しません。プラグインは `comi --no-tui --open-browser=false` を実行します。書庫を指定した場合だけ書庫引数を渡し、そのディレクトリを作業ディレクトリにします。空欄なら起動元のディレクトリを引き継ぎます。設定ファイルは Comigo が検索・読み込みます。設定ファイル欄には実際のパス、保存場所、実行プロファイル、形式、ファイルの有無を表示し、管理ボタンで Web 設定ページを開きます。

停止できるのはプラグインが起動して記録したプロセスだけです。ポート使用中は起動を拒否します。別の方法で起動したサービスをプラグインで管理するには、まず元の起動方法で停止してください。パネルを閉じても Comigo は停止しません。

## 読書と IP の切り替え

概要ではサーバーが返す読書 URL を使い、通常は送信に使われるネットワークインターフェースの IP が既定値になります。ローカルモードで外部アクセスが有効かつ複数の IP があると、QR コードの左右の矢印でアドレスを循環できます。読書リンク、QR コード、開く／コピー操作が選択に追従し、現在の IP は太字になります。IPv6 に対応し、プロトコル、ポート、URL パスを保持します。更新時も利用可能な選択を維持します。ローカル専用の待ち受けでは IP を切り替えません。

別の端末から読むには、外部アクセスを有効にし、その端末から選択した IP に接続できる必要があります。設定の外部アクセススイッチは Comigo の待ち受け範囲を変更し、再接続を待ちます。読み取り専用のサーバーでは変更できません。

UFW がインストールされ有効な場合、ファイアウォールボタンで既定インターフェースに直結するプライベート IPv4 サブネットから現在の TCP ポートへの接続を許可できます。管理者認証が必要です。取り消しは `omarchy-comigo` の印が付いたルールだけを削除し、ユーザー自身のルールを保持します。ルールが設定済みでも、ほかのネットワーク制限によって接続できない場合があります。

## リモートサービスに接続する

「リモート」を選び、設定にサービスの完全な HTTP(S) ホーム URL を入力して保存します。BasePath も含めてください。例：`https://reader.example/books/`。リモートサービスは起動済みで到達可能である必要があります。認証が必要ならログインします。

四つのページはリモートのデータを表示します。読書リンクと QR コードは設定したリモート URL を使い、ローカル IP の切り替えは行いません。ローカルのインストール、プロセス操作、ログ、CLI／書庫パス、外部アクセス、ファイアウォール操作は非表示です。ローカルとリモートの URL と認証セッションは別々に保持します。モード切り替えはサービスの起動・停止を行いません。Shell 起動時はローカルモードです。

## キーボード

`1`–`4` でページ選択、左右キーでページ切り替え、上下キーでスクロール、`r` で更新、Esc で閉じます。入力欄では通常の編集キーを使えます。

## 補足

自動起動は既定で無効です。サービスページで有効にすると、デスクトップセッションでプラグインが読み込まれた際にローカル CLI の起動を試みます。現在のセッションでも試行を開始し、systemd は使用しません。失敗後の試行間隔は最低 10 秒で、ログインセッションごとに最大三回です。プラグインや Shell の再読み込みでは回数をリセットしません。成功または手動のプロセス操作でそのセッションの自動試行を終了します。無効にすると後続の試行を中止し、上限に達した場合は手動で起動できます。

更新確認は結果、リリースページ、コピー可能な CLI 更新コマンドを表示し、インストールは行いません。接続中のサービスは API で確認し、停止中のローカルサービスには `comi desktop check-update` を使います。バイナリ更新後は Comigo を再起動してください。`comi desktop info` はサービスを起動せずにデスクトッププロトコル `1` を返します。

- 設定：`${XDG_CONFIG_HOME:-$HOME/.config}/omarchy-comigo/settings.json`。
- ログ：`${XDG_STATE_HOME:-$HOME/.local/state}/omarchy-comigo/comi.log`。
- プロセスと自動起動の記録：通常のデスクトップセッションでは `$XDG_RUNTIME_DIR/omarchy-comigo/`。

設定にパスワードやトークンは保存しません。認証セッションはモードと URL ごとにメモリ内で保持し、パスワードは送信後に消去します。Shell の再起動やトークン失効後は再ログインしてください。設定ファイルの外部変更は未編集の欄に反映され、編集中の内容は保持されます。全体の状態は約 30 秒ごと、開いたパネルの通信量は二秒ごと、設定ページでは同じ間隔で実行中の設定を取得します。通信量は現在の Comigo プロセスの HTTP 本文のみを集計し、マシン全体の通信量ではありません。プロセス再起動でゼロになります。

## トラブルシューティング

- **バージョン・API が未対応**：Comigo v1.3.5 以降を使用し、ローカルのデスクトップ連携は `comi desktop info` で確認してください。
- **オフライン・起動タイムアウト**：接続 URL と実際のサーバー設定を照合し、サービスログを確認してください。URL の入力ではサーバー設定は変わりません。
- **IP の矢印がない**：ローカルモード、外部アクセスの有効化、複数の IP を確認してください。
- **匿名接続でログイン欄が無効**：認証が必要な場合、またはログインセッションがある場合に有効になります。
- **インストールしたコードが表示されない**：`omarchy restart shell` を実行してパネルを開き直してください。

## 開発

ソースからインストールする場合：

```bash
git clone https://github.com/yumenaka/comigo-omarchy.git
cd comigo-omarchy
bash install.sh
```

スクリプトはプラグインを検証・コピーし、Omarchy Shell を再起動して有効化します。再実行するとソースの内容を反映できます。Shell の再起動でポップアップとプラグインのログインセッションは閉じますが、実行中の Comigo サービスは継続します。

```bash
omarchy plugin validate .
for script in install.sh bin/* tests/*.sh; do
  bash -n "$script" || exit 1
done
for test in tests/test-{ctl,refresh,modes,reading-ip,version,autostart,firewall}.sh; do
  bash "$test" || exit 1
done
COMIGO_TEST_CLI=/path/to/comi bash tests/test-default-library.sh
COMIGO_TEST_CLI=/path/to/comi bash tests/smoke.sh
```

QML テストには Wayland セッションが必要です。結合テストは隔離したサービスを使用します。[開発規約](AGENTS.md)、[Comigo 日本語ドキュメント](https://github.com/yumenaka/comigo/blob/master/README_JP.md)、Comigo サーバー内蔵の `/manual/ja-JP/comigo-omarchy` マニュアルも参照してください。
