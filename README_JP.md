# comigo-omarchy

![Comigo Omarchy プラグインのプレビュー](https://www.yumenaka.net/wp-content/uploads/2026/09/comigo-omarchy-plugin.png)

漫画・画像リーダー [Comigo](https://github.com/yumenaka/comigo) の Omarchy ステータスバープラグインです。日本語・英語・中国語に対応しています。

## プラグインのインストール

```bash
omarchy plugin add https://github.com/yumenaka/comigo-omarchy --enable
```

インストール後、ステータスバーの Comigo アイコンをクリックしてパネルを開きます。

## アンインストール

```bash
omarchy plugin remove yumenaka.comigo
```

設定と書庫は残り、サービスも停止しません。必要なら先にプラグインから停止してください。

## 依存関係

- **プラグイン本体**：Shell プラグイン対応の Omarchy、`bash`、`curl` が必要です。
- **Comigo**：ローカルモードには **v1.3.5 以降**の `comi` バイナリが必要です。未導入なら「サービス」からインストールできます。プラグインの追加だけでは自動インストールされません。リモートモードでは同じ最低バージョン要件を満たすサーバーが起動していればよく、ローカルのバイナリは不要です。
- **任意の機能**：バイナリのインストールには `tar` とシステム標準ツール、システムディレクトリへの導入には `pkexec` も使用します。ファイアウォール操作には `ufw`、`ip`、`pkexec` を使用します。

## 使い方

### ローカルモード（既定）

1. Comigo が未導入なら「サービス」からインストールします。既存のインストールは自動検出されます。検出されない場合は「設定」でバイナリのパスを指定してください。
2. インストール後、Comigo は自動的に起動します。インストール済みの場合は「起動」をクリックします。
3. 認証が必要なら「設定」でログインしてから、「概要」で読書リンクを開くか、QR コードを読み取ります。

書庫を指定する場合は「設定」にディレクトリを入力・保存し、ローカルサービスを再起動します。空欄なら Comigo の既定の動作を使用します。デスクトップへのログイン時に起動するには、「サービス」で自動起動を有効にしてください。

### リモートモード

1. サイドバーで「リモート」に切り替えます。
2. 「設定」にリモート Comigo の完全な URL（例：`https://reader.example/books/`）を入力し、「保存」をクリックします。
3. 認証が必要ならログインし、「概要」から読書リンクを開くか、QR コードを読み取ります。

モードを切り替えてもサービスは起動・停止しません。

## その他の機能

- **状態**：バージョン、書籍数、接続数、転送速度、累計通信量を確認できます。
- **LAN での読書**：ローカルの「設定」で外部アクセスを有効にすると、「概要」で利用可能な IP を選択できます。必要に応じてファイアウォールのボタンでポートを許可します。
- **サービス管理**：ローカルモードでは停止・再起動・ログ表示が可能です。更新確認は両モードで利用できます。操作できるのはプラグインが起動したプロセスのみです。更新確認は自動更新を行いません。
- **言語とショートカット**：サイドバーで言語を選択できます。`1`–`4` でページ切替、`r` で更新、`Esc` でパネルを閉じます。

パネルを閉じても Comigo は停止しません。接続できない場合はサービスの起動状態と URL を確認し、ローカルモードでは「サービス」のログも参照してください。

## 開発

ソースからのインストール・更新には `bash install.sh` を使用します。Omarchy Shell が再起動します。ソースから導入したコピーの削除は `bash install.sh --uninstall` です。開発規約と検証コマンドは [AGENTS.md](AGENTS.md)、詳細は Comigo 内蔵の `/manual/ja-JP/comigo-omarchy` マニュアルを参照してください。
