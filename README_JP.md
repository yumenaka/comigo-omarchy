# comigo-omarchy

[English](README.md) | [中文](README_ZH.md) | [日本語](README_JP.md)

漫画・画像リーダー [Comigo](https://github.com/yumenaka/comigo) の Omarchy ステータスバープラグインです。日本語・英語・中国語に対応しています。

## プラグインのインストール

Shell プラグイン対応の Omarchy、Bash、curl が必要です。Comigo サーバーは **v1.3.5 以降**を使用してください。

```bash
omarchy plugin add https://github.com/yumenaka/comigo-omarchy --enable
```

インストール後、ステータスバーの Comigo アイコンをクリックしてパネルを開きます。

## 使い方

### ローカルモード（既定）

1. 「サービス」タブで Comigo バイナリのインストールボタンをクリックし、案内に従います。インストール済みなら、この手順は不要です。
2. 「起動」をクリックして Comigo を起動します。
3. 「概要」から読書リンクを開くか、QR コードを読み取ります。

書庫を指定する場合は「設定」にディレクトリを入力して保存します。空欄なら Comigo の既定の動作を使用します。デスクトップへのログイン時に起動するには、「サービス」で自動起動を有効にしてください。

### リモートモード

1. サイドバーで「リモート」に切り替えます。
2. 「設定」にリモート Comigo の完全な URL（例：`https://reader.example/books/`）を入力し、「保存」をクリックします。
3. 認証が必要ならログインし、「概要」から読書リンクを開くか、QR コードを読み取ります。

リモート Comigo は事前に起動しておく必要があります。ローカルへの Comigo バイナリのインストールは不要です。モードを切り替えてもサービスは起動・停止しません。

## その他の機能

- **状態**：バージョン、書籍数、接続数、転送速度、累計通信量を確認できます。
- **LAN での読書**：ローカルの「設定」で外部アクセスを有効にすると、「概要」で利用可能な IP を選択できます。必要に応じてファイアウォールのボタンでポートを許可します。
- **サービス管理**：停止、再起動、ログ表示、更新確認に対応します。操作できるのはプラグインが起動したプロセスのみです。更新確認は自動更新を行いません。
- **言語とショートカット**：サイドバーで言語を選択できます。`1`–`4` でページ切替、`r` で更新、`Esc` でパネルを閉じます。

パネルを閉じても Comigo は停止しません。接続できない場合はサービスの起動状態と URL を確認し、「サービス」のログを参照してください。

## アンインストール

```bash
omarchy plugin remove yumenaka.comigo
```

設定と書庫は残り、サービスも停止しません。必要なら先にプラグインから停止してください。

## 開発

ソースからのインストール・更新には `bash install.sh` を使用します。Omarchy Shell が再起動します。ソースから導入したコピーの削除は `bash install.sh --uninstall` です。開発規約と検証コマンドは [AGENTS.md](AGENTS.md)、詳細は Comigo 内蔵の `/manual/ja-JP/comigo-omarchy` マニュアルを参照してください。
